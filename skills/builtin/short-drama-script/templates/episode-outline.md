# Episode outline skeleton

Fill every section. Drop a section only when the user explicitly asked for it to
be dropped.

## 1. Logline
One sentence: who wants what, who blocks it, what it costs.

## 2. Characters (max 3)
- NAME — want / secret / speech habit

## 3. Beats
| # | time | beat | situation change |
|---|------|------|------------------|
| 1 | 0-8s | cold open hook | |
| 2 | 8-20s | goal stated | |
| 3 | 20-35s | first obstacle | |
| 4 | 35-50s | reversal | |
| 5 | 50-70s | cost paid | |
| 6 | 70-85s | cliff hanger | |

## 4. Script
Scene heading (`INT./EXT. PLACE - TIME`), then dialogue only.

## 5. Next-episode hook
One sentence, unresolved.

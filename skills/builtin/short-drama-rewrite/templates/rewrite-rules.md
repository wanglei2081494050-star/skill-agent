# Rewrite rules (apply in order)

1. **Hook first.** The opening line must state a stake or a threat. If the
   original opens with a greeting, move the greeting to line 2 or delete it.
2. **One idea per line.** Split any line with two clauses joined by "而且/并且/
   所以" into two lines; delete the weaker one if both say the same thing.
3. **Speak, don't write.** Written connectives (因此 / 然而 / 综上所述) become
   spoken ones (所以 / 可是 / 你看).
4. **No self-explanation.** A character must not explain their own motivation.
   Move the motive into the other character's reaction.
5. **Numbers stay exact.** Amounts, dates, and names must not change.
6. **Hook at the tail.** The last line must leave an unanswered question.
7. **Length guard.** Changes must keep the episode within +/- 10% of the
   original character count.
